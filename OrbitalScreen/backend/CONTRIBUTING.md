# Contributing to OrbitalScreen

Welcome aboard! This repository is governed by the **OrbitalScreen Compliance Protocol and Stability Enforcement**, ensuring every contribution is reproducible, audit‑ready, and cockpit‑grade.

## 🚦 Contribution Standards

| Behavior Type | Description |
|---------------|-------------|
| 🟢 **Positive** | Clear commits, signed contributions, respectful collaboration, reproducible code |
| 🟡 **Caution** | Unclear commit messages, missing tests, off-topic comments |
| 🔴 **Unacceptable** | Unsigned commits, merge commits on protected branches, bypassing CI/CD, disruptive behavior |

> 🛡️ All contributors are expected to uphold green-level standards. Yellow behavior may receive a warning. Red-level violations may result in removal or blocked contributions.

## 🛠️ Pull Request Requirements

- ✅ Minimum **3 approvals** from maintainers or administrators  
- ✅ All commits must be **signed and verified**  
- ✅ CI/CD pipeline must pass:
  - Build, lint, and test
  - CodeQL vulnerability scan  
- ✅ **Linear history only** — merge commits are prohibited  
- ✅ Status checks must pass before merging  
- ✅ Only authorized roles may bypass enforcement

## 🧭 Target Branches

- `OrbitalScreenStable` (primary compliance branch)  
- `release-*` (if applicable)

Experimental branches (`dev`, `feature-*`) are exempt from enforcement but must be rebased before merging.

## 🛡️ Enforcement Authority

Maintainers have final authority on contribution decisions.  
This ensures OrbitalScreen remains compliance‑ready, audit‑ready, and trusted as a service node.

## 🛰️ Final Note

OrbitalScreen is built to empower everyone.  
Your contributions help shape a future that’s modular, reproducible, and under control.
